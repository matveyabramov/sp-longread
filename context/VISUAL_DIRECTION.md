# VISUAL DIRECTION / ECHO

This file supplements `ECHO_BRIEF.md`.

`ECHO_BRIEF.md` remains the source of truth for:
- concept;
- article structure;
- content logic;
- interaction logic;
- constraints.

This file records the CURRENT visual direction decisions for the first media / visual integration pass.


## 1. OVERALL VISUAL FEEL

The longread should feel like:

- dark editorial;
- cinematic;
- premium;
- slightly retro-screen / CRT;
- media-aware;
- controlled, not chaotic.

It should NOT feel like:

- SaaS;
- dashboard;
- AI product UI;
- collage explosion;
- random Pinterest moodboard;
- nostalgic retro-for-retro’s-sake;
- cyberpunk;
- VHS gimmick website.

Use retro-screen language only as a supporting layer, not as the main gimmick.


## 2. PALETTE / ATMOSPHERE

Keep the existing dark editorial base.

Use:
- deep dark background;
- warm light text;
- accent green from the project (`#D6FF3B` or very close);
- subtle CRT / signal / scanline / glow references only where useful.

Do NOT flood the entire site with noisy retro effects.

Retro elements must stay restrained.


## 3. HERO DIRECTION

The hero is now typography-first with one large visual object.

### Key decisions

- Remove the current abstract blurred circles / decorative glow composition.
- Remove the oversized standalone “ЭХО” from the main hero composition.
- Keep the project label / brand only in the header.
- Increase the size and visual weight of the main headline.

Headline:

“Ты смотришь сериалы без перевода.
Сколько шуток из них ты правда понял?”

### Composition direction

Use a composition inspired by the **Spartak Rugby** reference logic:
- very large typography;
- one dominant visual object;
- object and typography interact spatially;
- asymmetrical balance;
- strong full-screen impact.

Do NOT copy Spartak literally.

### Hero asset

The current hero asset is the **TV-head person** image.

Important:
- the current asset may still include its original atmospheric background;
- do NOT assume it must be perfectly cut out;
- first try to integrate it using:
  - large crop;
  - masking / fade;
  - compositional framing;
  - overlay if needed.

The goal is to test the concept first.

### Hero mood

Use the TV-head image as the main surreal / media-aware anchor.

The hero may contain subtle:
- CRT texture;
- signal feel;
- soft screen glow;
- restrained interference cues.

Do NOT turn the hero into a retro collage.

This section uses an **elephant motif**.

### Current asset state

A temporary elephant asset is provided.

It may still have a background.
It is temporary.
The goal is to test the concept, not to finalize the illustration.

### Integration intent

For the current pass:
- use the temporary elephant as a visual motif;
- make it appear from below / enter the composition in a scroll-aware way;
- treat it as an object interacting with the text, not as a simple inline illustration.

Important:
- for now, use ONE elephant only;
- do NOT simulate three different elephants yet;

### Desired feeling

The elephant should feel:
- a little strange;
- literal;
- memorable;
- slightly disruptive;
- conceptually tied to idiomatic meaning.

Not cute.
Not playful meme art.
Not generic illustration.

## 9. FILM CASES / “МЕЖДУ СТРОК”

This is the main media-heavy section.

The interaction logic remains based on the Electra-inspired pattern:
- phrase list;
- hover / focus reveals media;
- active phrase dominates;
- click / open reveals popup detail.

### Critical visual direction

The media should no longer feel like a small preview card.

Instead:
- the hovered / focused case media should become a near-fullscreen or fullscreen background for the section;
- use large cover media;
- use dark overlay / gradient for text legibility;
- keep the phrase list readable in front.

### Media assets

Current temporary media files are in this order:

- `case-01` → Frozen
- `case-02` → The Lion King
- `case-03` → Austin Powers
- `case-04` → A Bug’s Life
- `case-05` → The Shining

Important:
these are working visual placeholders for concept testing.
Some films / scenes may be replaced later.

Therefore:
- structure the section so media files can be swapped easily;
- do not overfit the whole design to the current exact clips.

### Video behavior

Use the clips as:
- autoplay;
- muted;
- loop;
- playsinline;
- cover.

Keep playback smooth and simple.

### Popup direction

Do not deeply redesign every popup in this pass.

Only ensure:
- the media-driven list experience works;
- popups remain readable and structurally coherent.
